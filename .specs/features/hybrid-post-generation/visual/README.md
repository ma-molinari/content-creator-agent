# Amostras do catálogo provisório

As três imagens foram renderizadas pelo pipeline estruturado em 1080 × 1350, com as fontes Inter e Plus Jakarta Sans carregadas do Google Fonts. Usam o mesmo texto e as mesmas cores para facilitar a comparação dos layouts `hero`, `editorial` e `quote`.

São exemplos genéricos sem imagens de marca; não validam todos os estilos, quantidades de conteúdo ou combinações de elementos. O responsável aprovou o catálogo inicial V1 com base nessas amostras em 2026-11-18. A geração estruturada permanece desativada por padrão até a aceitação operacional.
